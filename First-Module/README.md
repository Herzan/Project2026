# Overview

As a software engineer I wanted to strengthen my JavaScript skills by creating a program that solves a everyday problem: keeping track of tasks. I was curious about how a program could store data allow a user to add and update items and keep that information organized while the program runs.

The software I made is a Task Manager command-line program. It was built with JavaScript running on Node.js. When you run it the program shows a menu that allows you to add a task view all current tasks mark a task as complete and delete a task. Each task records its description and its completion status.

My goal in building this software was to become comfortable with core programming concepts in JavaScript such as variables, functions arrays, objects, loops and conditional logic. I wanted to practice reading user input updating a data structure based on that input and showing results back, to the user clearly. I did this because I plan to build on these fundamentals with complex JavaScript projects later. Getting these basics right helps a lot.

# Development Environment

I used Visual Studio Code as my IDE. I used Git/GitHub for version control.

I. Tested the program locally using Node.js. I tested each menu option manually by running the program and entering inputs to make sure tasks were added, listed completed and removed correctly.

I used JavaScript (Node.js) to build this program. I used the built-in readline module to read input from the user, in the standard JavaScript arrays and objects to store and manage the list of tasks.
